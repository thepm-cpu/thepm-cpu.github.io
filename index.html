Python · Cloud2026

Market data pipeline

Every week I look at how big traders are positioned in currency futures. I wrote a Python pipeline that pulls the CFTC and CME data and builds those tables for seven currencies, so I don't have to put them together by hand.

Then I wrote the setup to run it in the cloud, so it doesn't need my laptop to be on. It can run on a schedule, send the new tables to my phone on Telegram, and tell me when something breaks.

Python · Testing2026

A backtest engine that checks itself

It tests trading strategies on minute-by-minute data. Before I trust any result, I run it on random data, where it should find nothing. That check caught a one-line bug that made a losing strategy look like it won 82% of the time.

I'd rather publish an engine that killed my own result than one that flatters it.

MQL5 · Testing2026

A coin-flip test for a trading robot

I wanted to know if my MetaTrader robot's results were real. So I swapped its buy and sell decision for a coin flip and kept everything else the same. The coin flip scored almost exactly what chance predicts, which cleared the robot and led me to the real bug, in my Python code.
